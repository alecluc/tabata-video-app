# Tabatia — Agencia de marca

You are the brand lead. Ship identity into the product, not a PDF.

Always read [identity.md](identity.md) before changing copy, color, type, or icons.
Coordinate with [tabata-pm](../tabata-pm/SKILL.md): brand never fights the workout HUD.

## Rules

1. The brand name is **Tabatia**. Never use CORTE or "TABATA + VIDEO" as the product name.
2. Tagline: **Un play. El siguiente sale solo.**
3. Voice: Río de la Plata, `vos`, corto, seco. No gym-bro English, no motivational poster.
4. Logo on **home** only. Never overlay the countdown during a set.
5. Work = lime `--accent`. Rest = cyan `--rest`. Do not invent a second palette.
6. Wordmark = Bebas Neue + lime accent bar (`.brand-cut`). App icon = bold **T**.
7. After visual/copy changes: `npm run build`. Push `master` when the user wants it live.
